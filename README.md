# Sknoww Tap

## How do I install these formulae?

`brew install sknoww/tap/<formula>`

Or `brew tap sknoww/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sknoww/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
